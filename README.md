# Flying Images website

Statische site (geen framework). Alle inhoud en prijzen staan in `src/data.mjs`.

- `npm run build` → `dist/` (Vercel, schone URL's, sitemap, robots)
- `npm run preview` → `preview/` (relatieve links, lokaal te openen)

Vercel: importeer de repo, de instellingen staan in `vercel.json`.
Contactformulier: vul je Web3Forms-key in bij `web3formsKey` in `src/data.mjs`.
